skill-installer

浏览并安装 OpenAI 官方 curated、experimental 或指定 GitHub 路径中的 Codex Skills。

适用场景

· 为 Codex 增加官方能力
· 从可信仓库安装团队技能
· 查看可安装技能清单

用法

$skill-installer
$skill-installer gh-fix-ci

官方来源

$skill-installer
